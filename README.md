# Дело — менеджер задач

Адаптивный сайт на HTML, CSS и JavaScript с [DummyJSON API](https://dummyjson.com/docs/todos). Без зависимостей и API-ключей.

## Запуск

Установите Node.js 18 или новее, откройте папку проекта в терминале:

```sh
npm start
```

Откройте http://127.0.0.1:4173. Также можно использовать Live Server для `index.html`. Для другого порта задайте переменную `PORT`.

## Возможности

- Загрузка всех задач и людей (`limit=0`), показ задач порциями по 30.
- Создание, редактирование названия / исполнителя / статуса, удаление с подтверждением.
- Поиск, фильтры по статусу и человеку, алфавитная сортировка задач и людей через API.
- Логин, аватар, ID человека и номер задачи.
- Раздел «Люди», профиль с контактами, адресом, компанией и другими полями по образцу.
- Все задачи конкретного человека и создание задачи прямо из профиля.
- Сортировка задач в профиле: по алфавиту, номеру и статусу; выбранный порядок сохраняется в браузере.
- Редактирование имени, фамилии, почты и телефона человека.
- Счётчики и процент выполнения, состояния загрузки, ошибок и пустых результатов.
- Локальное сохранение изменений, кэш для повторного открытия без сети.
- Адаптивная верстка для телефона, управление с клавиатуры, нативные диалоги.

## Особенности DummyJSON

DummyJSON имитирует POST, PUT и DELETE и не сохраняет изменения на сервере. После успешного ответа сайт хранит изменения в `localStorage` текущего браузера. Новые задачи получают уникальный внутренний ID и отдельный видимый номер; их последующее изменение и удаление выполняется локально, поскольку сервер не сохраняет созданные объекты. Изменения не синхронизируются между устройствами. Очистка данных сайта удалит локальные изменения.

Сортировка делает новый GET с `sortBy` и `order`. Затем локальная сортировка учитывает созданные и изменённые записи. Для пользователей запрашиваются только поля, показанные в интерфейсе. Пароли и банковские данные не запрашиваются.

## API

| Действие          | Запрос                                                     |
| ----------------- | ---------------------------------------------------------- |
| Все задачи        | GET `/todos?limit=0`                                       |
| Сортировка задач  | GET `/todos?limit=0&sortBy=todo&order=asc`                 |
| Люди              | GET `/users?limit=0&sortBy=firstName&order=asc&select=...` |
| Создание          | POST `/todos/add`                                          |
| Изменение         | PUT `/todos/:id`                                           |
| Удаление          | DELETE `/todos/:id`                                        |
| Изменение профиля | PUT `/users/:id`                                           |

## Проверка

Для тестов нужен Node.js 22.12+; зависимости используются только при разработке.

```sh
npm ci
npm run check
npm test
```

Для статического хостинга достаточно `index.html`, `style.css` и `app.js`. Сервер `server.cjs` нужен только для локального просмотра.
